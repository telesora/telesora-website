# Telesora website

Source of the website https://telesora.com in English, Spanish and Ukrainian.

Telesora connects care home staff with a real doctor by video at any hour. AI prepares the case, writes the notes and sends reminders. The doctor always decides. Telesora is in development.

## About this site

- Plain HTML, CSS and JavaScript. No build step.
- No cookies, no analytics and nothing loaded from other companies. Fonts and images come from this repository.
- The contact form only opens the visitor's own mail app. It sends nothing by itself.
- Hosted on Cloudflare.

## Structure

- `/` English pages
- `/es/` Spanish pages
- `/uk/` Ukrainian pages
- `/assets/` styles, scripts, fonts, logos, social preview image and the two-page overview PDFs

## Preview on your computer

From the repository folder, run `python3 -m http.server 8000` and open http://localhost:8000.
